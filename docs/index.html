The GitHub repos Hacker News keeps recommending

Every github.com link in HN comments and stories since 2008, ranked by how many different people recommended it. No votes to game, no stars-for-stars: just commenters saying "check this out".

How it works. A crawler pulls every Hacker News comment and story that links to github.com from the HN Algolia API, extracts and normalises the repo links, and looks each repo up on GitHub (following renames, dropping deleted repos). Each person counts once per repo, at the weight of their strongest mention: a link to the repo itself counts 1, a file 0.75, an issue, PR or commit 0.25 (those are usually bug reports, not recommendations). Recommendation language ("check out", "I use", "highly recommend") adds 25%, and self-promotion counts half and never as a recommender. A story that links the repo counts once for the submitter, plus a bonus for its points. Trending halves a mention's weight every 90 days. A repo is listed once two different people have recommended it, or it had a 100+ point story.
